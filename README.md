# SLGAN — Ayurvedic Shop

A Kotlin + Jetpack Compose Android starter for an Ayurvedic medicines storefront.

## Features
- Ayurvedic-inspired leaf-and-herb app icon and green/cream theme
- Mobile number or email entry screen
- Demo continue flow into the storefront (not real OTP/authentication)
- Search, product categories, product cards and cart quantity controls
- Home, Categories, Cart and Profile bottom navigation
- Sample product data only; no backend, payments, or medical advice

## Build
Open this repository in Android Studio, allow Gradle sync, then run the `app` configuration on an Android device or emulator.

- Android min SDK: 24
- Kotlin + Jetpack Compose + Material 3

## Important
This is a UI starter. Login is a local demo flow and does not verify phone numbers/emails. Before production, integrate secure authentication, a backend/catalog, verified product information, privacy/terms, and a compliant payment provider. Do not add API keys or secrets to this public repository.
